Apache 2.4.x Target Lab

Máy Chủ Mục Tiêu Kiểm Thử - ATTT Portal

Môi trường giả lập Web Server Apache để phục vụ rà quét Nmap, Reconnaissance, nhận diện Tech Stack và quét thư mục nhạy cảm.

  • Port HTTP: 80 (Host: 8088)
  • Mục tiêu kiểm thử: http://localhost:8088/
  • Thư mục nhạy cảm có sẵn để test: /backup.zip, /robots.txt, /admin/
